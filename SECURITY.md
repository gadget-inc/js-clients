## Security maintainers

The security maintainers are responsible for investigating vulnerability
reports, assessing dependency vulnerabilities, developing and reviewing
security fixes, and coordinating security releases for this repository
and its published packages.

- [Nicholas Heggart-Richer](https://github.com/pistachiobaby)
  (@pistachiobaby) — Maintainer responsible for security maintenance.

Security maintainers work with other Gadget maintainers to validate
reported issues, add regression tests, and coordinate disclosure.
